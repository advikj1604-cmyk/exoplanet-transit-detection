# exoplanet-transit-detection
Deep Learning for Exoplanet Transit Detection: Raw Flux Snippets vs. Phase-Folded Representations
This repository contains code for the study "Deep Learning for Exoplanet Transit Detection: Raw Flux Snippets vs. Phase-Folded Representations". Two 1D CNN pipelines are compared across 20 independent train-test splits using Kepler DR24 TCE data.


Summary - The automated detection of exoplanet transits in stellar light curves has become an increasingly important challenge in modern astronomy, as space missions such as Kepler have generated more data than can be manually reviewed. Deep learning models, particularly convolutional neural networks, have shown strong potential for automating this process. A key unresolved question is whether phase-folded and binned light curve representations offer a consistent advantage over raw flux snippets as model inputs, particularly under limited data conditions. We hypothesized that phase-folded representations would outperform raw flux snippets when paired with an appropriate neural network architecture, particularly with sufficient training time. We trained and evaluated five model configurations across approximately 1,000 Kepler Threshold Crossing Events from the DR24 catalog, varying both input representation and architecture across 20 independent train-test splits. At 100 training epochs, raw snippet and phase-folded models performed comparably, with mean AUC values within one percentage point of each other. However, as training extended beyond 150 epochs, phase-folded models using a lightweight architecture began to consistently outperform raw snippet models, ultimately achieving a mean AUC of 0.849 compared to 0.832 for the best raw snippet configuration. We additionally found that BatchNormalization severely degraded phase-folded model performance while having minimal impact on raw snippet models, suggesting that input representation and architectural choice interact in ways not previously characterized. These findings support the use of phase folding for exoplanet transit detection even under limited data regimes, provided the architecture is appropriately matched to the input representation.
